# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Project participants must provide a respectful, harassment-free environment.
Examples of unacceptable behavior include personal attacks, discriminatory
language, harassment, and publishing another person's private information.

Report conduct concerns privately to the repository owner. Reports will be
reviewed promptly and confidentially. Maintainers may remove, edit, or reject
contributions and may temporarily or permanently ban contributors whose conduct
is inappropriate.
